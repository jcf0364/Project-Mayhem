# Project-Mayhem
GAME OF THE YEAR

## About the Game
Project Mayhem is a fast paced 2D platform fighter where players battle on a platforms and try to defeat their opponent. Each player has a health bar and a set number of lives. The last player standing wins the round.

Game Details

Genre: 2D Platform Fighter \
Engine: Unity \
Game Mode: Local Multiplayer \
Players: 2 \
Platform: PC (Mac, Windows)

## Features
- Main menu with Play, Options and Quit
- Round countdown before each fight
- Attack system and health bars
- Lives system
- Results screen at the end of a match
- Settings menu with screen resolution options (filtered to the monitor's refresh rate)

## Controls
Player 1: \
Movement: WASD, Attack: F \
Player 2: \
Movement: Arrows, Attack: Shift \

Note: Controls can be Remapped in the options menu

## Prerequisites
Running the Release Build:
- A compatible Windows PC. 
- A keyboard for local multiplayer controls. 
- Sufficient disk space to extract and run the game files. 
- No Unity Editor installation is required to run the release build. 

Running the Unity Project:
- Unity Hub. 
- The Unity Editor version: 6000.5.6f1 
- Git, if cloning the repository. 
- Sufficient disk space for the project files and required Unity packages.

## Installation
Run the Built Game:

1. Download or clone the Project Mayhem repository.
2. Navigate to the release or build folder.
3. Locate the game executable.
4. Run the executable to launch the game.
5. Select Play from the main menu to start a match.

## How to Play
1. Launch Project Mayhem
2. Select Play from the main menu
3. Login to your profiles (guest login available)
4. Choose your characters
5. Select an arena
6. Wait for the round countdown to finish, then battle beigns
7. Attack your opponent while avoiding incoming attacks.
8. Reduce your opponent's health and use the lives system to your advantage.
9. Continue fighting until one player has no lives remaining.
10 View the results screen to see the match outcome. \
REPEAT
